# Projects
Here are some of the projects I have worked on over the last few years. Please note that these have all been solo projects and most have not been maintained, and also that many of these projects were written while I was still learning the languages, so may not use best practices.

| Project | Date Started | Languages | Description | 
| :---: | :---: | :---: | :--- |
| [mui](https://github.com/txm073/mui) | 08/2026 | `C++`, `Kotlin` | An app development framework built on top of [ImGui](https://github.com/ocornut/imgui), aiming to make it easy to create apps that run smoothly on desktop & mobile with minimal dependencies. This is the project I am most frequently working on. |
| [mirror](https://github.com/txm073/mirror) | 07/2026 | `C++` | A (pre C++26) library implementing reflection. It can generate both object and relational metadata with a non-invasive user API and features several consumers such as Serialisers, Hashers, [ORM](https://en.wikipedia.org/wiki/Object%E2%80%93relational_mapping) & more. |
| [University Project](https://github) | 06/2026 | `Python` | A university coursework project using PyTorch to find and visualise [Geodesics](https://en.wikipedia.org/wiki/Geodesic) on a torus. | 
| [Digit Recognition](https://github.com/txm073/digit-recognition) | 01/2025 | `Python` | A basic parser for [rnote](https://github.com/flxzt/rnote) that can generate a character dataset and scan documents, and a neural network that can recognise and evaluate mathematical expressions. |
| [screentime](https://github.com/txm073/screentime) | 10/2024 | `C` | An experimental program to monitor and close Unix processes. |
| [Ultimate Health](https://github.com/txm073/ultimate_health) | 10/2023 | `Dart`, `Python` | A mobile app I made as a coursework project during my computer science A-level class. It is a workout tracker and recipe app. | 
| [Kashyyyk Hotel](https://github.com/txm073/kashyyk-hotel) | 11/2022 | `C` | This is an A level coursework project for learning C. It is a command line interface for an imaginary hotel booking system. |
| [Project Manager](https://github.com/txm073/.manager) | 02/2022 | `Python` | A small Python automation program to help organise projects stored on GitHub. |
| Cryptography | 01/2022 | `C++`, `Python` | Basic implementations of [RSA](https://github.com/txm073/rsa), [Elliptic Curve](https://github.com/txm073/ecc) & [AES-GCM](https://github.com/txm073/aes) encryption algorithms. |
